# RecordingDetailScreen 测试用例

## 1. 播放器
- 1.1 首次点击 "▶ Play" 开始播放,进度条随播放进度实时更新
- 1.2 播放中按钮文案变为 "⏸ Pause",再次点击暂停,进度条停止推进
- 1.3 时间显示区正确展示当前播放位置/总时长(mm:ss)
- 1.4 点击进度条任意位置可跳转到对应播放位置(seek)
- 1.5 点击倍速按钮循环切换 1x → 1.5x → 2x → 1x,切换后实际播放速率同步变化
- 1.6 播放控制按钮按下时均有背景变化反馈

## 2. 转写文本(Transcript)
- 2.1 有转写内容时按句子拆分逐条展示
- 2.2 无转写内容时显示 "No transcript yet"
- 2.3 播放进行中,当前播放位置对应的句子高亮显示(背景色+加粗)
- 2.4 点击任意一条转写句子可跳转播放位置到该句子起始处
- 2.5 点击句子时有按压态视觉反馈

## 3. AI 摘要
- 3.1 摘要已生成时直接显示摘要文本
- 3.2 摘要未生成(aiSummary 为 null)时显示 loading 指示器+"Generating summary (处理阶段)…" 文案
- 3.3 处理未完成时页面会轮询,处理完成后摘要区域自动从 loading 态切换为正式内容,无需用户手动刷新页面

## 4. 操作按钮
- 4.1 点击 "Download Recording" 触发系统下载/打开链接行为(不崩溃)
- 4.2 点击 "Share Transcript" 触发系统分享面板(有转写内容时);无转写内容时不应崩溃
- 4.3 两个按钮按下均有背景变化反馈

## 5. 协调员备注
- 5.1 备注输入框可输入多行文字
- 5.2 已有备注时初始值正确回填
- 5.3 点击 "Save Note Only" 保存备注但不标记已处理,保存中按钮显示 loading、禁用防重复点击
- 5.4 点击 "Mark Processed"(未处理 → 已处理)保存并标记已处理,按钮文案变化(Mark Processed → Marked Processed)
- 5.5 两个保存按钮为互斥禁用(一个保存中另一个也不可点)

## 6. 页面整体
- 6.1 内容整体可滚动(播放器+转写+摘要+操作+备注都在同一个可滚动容器内,不会因内容多而被截断)
- 6.2 页面首次加载完成后内容有淡入过渡
- 6.3 加载中显示居中 loading 指示器
