# NotificationCenterScreen 测试用例

## 1. 列表展示
- 1.1 顶部显示 "Unread N" 未读计数
- 1.2 加载中显示居中 loading 指示器
- 1.3 加载完成后列表按时间展示通知标题、正文(最多两行,超出省略)、发送时间
- 1.4 未读通知有淡蓝色背景高亮和左侧圆点标记
- 1.5 已读通知无高亮背景、无圆点
- 1.6 列表为空时显示 "No notifications"
- 1.7 内容加载完成后有淡入过渡

## 2. 仅看未读开关
- 2.1 打开 "Unread only" 开关后,列表只显示未读通知
- 2.2 关闭开关后恢复显示全部通知

## 3. 点击通知
- 3.1 点击未读通知,该通知立刻标记为已读:背景高亮和圆点以淡出动画消失(不是瞬间消失)
- 3.2 点击已读通知不重复触发标记已读请求
- 3.3 通知关联了案件(caseId)时,点击后跳转到对应的案件详情页(跨 tab 跳转到 Cases tab 下的 CaseDetail)
- 3.4 通知未关联案件时,点击后仅标记已读,不发生跳转

## 4. 下拉刷新
- 4.1 下拉可触发刷新,刷新指示器正确显示和消失

## 5. 视觉反馈
- 5.1 通知行按下时有透明度反馈
