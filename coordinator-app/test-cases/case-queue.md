# CaseQueueScreen 测试用例

## 1. Tab 切换
- 1.1 默认进入 "Needs attention" (queue) tab,列表加载对应数据
- 1.2 依次点击 "My to-dos"/"In progress"/"Closed"/"All" 四个 tab,每次都能正确切换、加载对应数据、高亮当前 tab(下划线+文字变色)
- 1.3 "Needs attention" tab 上出现新案件角标(红色圆点+数字),数字随新案件到达累加,超过 99 显示 "99+"
- 1.4 切到 "Needs attention" tab 或下拉刷新后角标清零
- 1.5 5 个 tab 标签在窄屏下不换行、不裁切(numberOfLines=1 + adjustsFontSizeToFit 生效)

## 2. 统计条
- 2.1 列表非空时,顶部显示 "N cases" 统计文案
- 2.2 存在超时案件时额外显示 "N overdue"(红色)
- 2.3 存在 VIP 客人案件时额外显示 "N VIP"(棕色)
- 2.4 列表为空时统计条不显示

## 3. 搜索
- 3.1 在非 "All" tab 下输入搜索词,列表实时按客人昵称/扰动标题/确认号本地过滤
- 3.2 切到 "All" tab,输入搜索词并按回车(提交),触发服务端搜索接口
- 3.3 搜索词清空后列表恢复完整

## 4. 优先级筛选
- 4.1 默认选中 "All priorities"
- 4.2 点击 high/normal/low 任一筛选项,列表只显示对应优先级案件,筛选项高亮
- 4.3 优先级筛选可与搜索词同时生效(交集)

## 5. 案件卡片
- 5.1 卡片显示客人昵称、扰动标题、确认号、等待时长(人类可读格式如 "2h 30m" 而非原始 TimeSpan 字符串)、优先级标签
- 5.2 高优先级案件的优先级标签背景为醒目色(红色系)
- 5.3 超时案件显示 "Overdue" 徽章且有脉冲透明度动画
- 5.4 VIP 客人显示 "VIP Guest" 标签
- 5.5 已转人工的案件显示英文的转人工原因(不出现未翻译的中文原文)
- 5.6 点击卡片主体跳转到案件详情页
- 5.7 按下卡片有按压态背景变化反馈

## 6. 拨打电话
- 6.1 点击卡片内 "Call Guest" 按钮,不触发卡片整体的 onOpen 跳转(阻止冒泡)
- 6.2 点击后按钮显示 loading 指示器,同一卡片另一按钮("Call Hotel")在通话发起期间应被禁用
- 6.3 离线状态下(无网络)两个通话按钮均为禁用态
- 6.4 通话发起成功后跳转到 InCall 页面

## 7. 下拉刷新与空状态
- 7.1 下拉列表可触发刷新,刷新中显示系统刷新指示器
- 7.2 筛选结果为空时显示 "No cases match these filters" 提示文案

## 8. 加载与过渡
- 8.1 首次加载时显示居中大号 loading 指示器
- 8.2 数据加载完成后列表内容有淡入过渡,不是瞬间出现
