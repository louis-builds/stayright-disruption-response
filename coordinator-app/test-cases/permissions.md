# PermissionsScreen 测试用例

## 1. 初始状态
- 1.1 首次进入页面,麦克风、通知两行权限状态均为 "Not requested",状态点为灰色
- 1.2 页面标题 "These permissions are needed to get started" 正确显示
- 1.3 页面有淡入+上移的进场动画

## 2. 请求权限 - 麦克风
- 2.1 点击麦克风行的 "Request" 按钮,按钮内显示 loading 指示器,不可重复点击
- 2.2 授权成功后,状态变为 "Granted",状态点变绿,图标背景变绿,图标容器有一个短暂的放大回弹动画
- 2.3 拒绝授权后,状态变为 "Denied",状态点变红,行内出现"Open system settings to enable →"链接
- 2.4 点击该链接可跳转系统设置(Web 预览下验证链接可点击、不报错即可)
- 2.5 已 Denied 状态下再次点击按钮,文案变为 "Retry" 而不是 "Request"

## 3. 请求权限 - 通知
- 3.1 同 2.1-2.5,针对通知权限重复验证

## 4. 继续
- 4.1 无论权限状态如何,底部 "Continue" 按钮始终可点击(不因未授权而禁用)
- 4.2 点击 Continue 触发 onContinue 回调,离开该页面
- 4.3 按下 Continue 有按压态视觉反馈(轻微变暗)

## 5. 布局
- 5.1 两行权限卡片之间有合理间距,不拥挤也不过于空旷
- 5.2 窄屏下文案不换行错位、按钮不被挤出卡片
