# SettingsScreen 测试用例

## 1. 个人信息
- 1.1 头像圆圈内显示昵称首字母大写
- 1.2 显示协调员昵称、邮箱、电话
- 1.3 昵称为空时头像显示占位字母 "C",姓名区域显示 "Coordinator" 兜底文案

## 2. 通知偏好
- 2.1 四个开关(新转人工案件/来电/转写摘要就绪/失败告警)加载完成前不渲染(避免闪烁默认值)
- 2.2 加载完成后按已保存的偏好正确回显开关状态
- 2.3 切换任一开关后状态立即变化并持久化(下次进入页面保持)

## 3. 修改密码
- 3.1 当前密码或新密码为空/新密码不足 8 位时,点击提交显示 "New password must be at least 8 characters" 错误提示,提示有淡入动画
- 3.2 输入合法的当前密码+新密码(≥8位),提交后按钮显示 "Updating…" 并禁用
- 3.3 提交成功后显示绿色成功提示 "Password updated",两个输入框清空
- 3.4 提交失败(如当前密码错误)显示红色错误提示,输入框内容保留(不清空,便于用户修正)
- 3.5 提交按钮按下时有背景变化反馈

## 4. 权限状态
- 4.1 显示麦克风、通知两项系统权限的当前状态(Granted/Not granted),状态旁有对应颜色的圆点(绿色=已授权,灰色=未授权)

## 5. 关于
- 5.1 显示 App 版本号,读取不到时显示 "—" 兜底

## 6. 退出登录
- 6.1 点击 "Sign Out" 触发登出流程,登出后应返回登录页(需在导航层面验证)
- 6.2 按钮按下时有更深的红色背景反馈

## 7. 页面整体
- 7.1 页面内容整体可滚动
- 7.2 首次加载完成后内容有淡入过渡
