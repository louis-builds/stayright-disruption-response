# InCallScreen 测试用例

## 1. 通话建立中(connecting)
- 1.1 进入页面初始状态显示 "Connecting…" 文案,文案有脉冲透明度动画(反复渐隐渐现)
- 1.2 顶部显示被叫方类型(Guest/Hotel)
- 1.3 该阶段不显示 "Recording" 徽章
- 1.4 页面整体有淡入进场动画

## 2. 通话接通(in_progress)
- 2.1 状态轮询检测到接通后,"Connecting…" 文案切换为计时器格式(mm:ss),脉冲动画停止
- 2.2 计时器每秒递增
- 2.3 出现 "Recording" 徽章,徽章以淡入方式出现(不是瞬间蹦出)
- 2.4 徽章内的红点有脉冲透明度动画,持续闪烁

## 3. 控制按钮
- 3.1 点击 "Mute" 按钮切换静音状态,按钮背景变为高亮色,图标从🎤变为🔇
- 3.2 再次点击恢复未静音状态
- 3.3 点击 "Speaker" 按钮切换免提状态,按钮背景变为高亮色
- 3.4 两个控制按钮按下时均有可见的透明度反馈

## 4. 挂断通话
- 4.1 点击 "End Call" 按钮,按钮文案变为 "Ending…" 且不可重复点击
- 4.2 通话终态(completed/failed/no_answer)到达后自动跳转到 CallSummary 页面,不会重复跳转多次
- 4.3 跳转发生后原页面不应残留计时器等副作用(卸载时清理定时器)

## 5. 视觉
- 5.1 深色背景,文字对比度清晰可读
- 5.2 挂断按钮为醒目红色,按下有更深的红色反馈
